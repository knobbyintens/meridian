# Label guide

| Label | Meaning |
| --- | --- |
| `kind/bug` | Defect in shipped behaviour |
| `kind/feature` | New capability request |
| `kind/chore` | Maintenance / cleanup work |
| `priority:P0` | Drop everything, customer impact |
| `priority:P1` | High priority, next release candidate |
| `priority:P2` | Normal priority |
| `status:stale` | No owner, no activity, candidate for cleanup |
| `duplicate` | Already tracked elsewhere |
| `release-blocker` | Added only by the backlog sweep |
| `needs-spec` | Added only by the backlog sweep |
