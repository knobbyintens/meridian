# Meridian

Meridian is the customer-facing platform that powers accounts, billing, checkout
and the admin console. This repository is the shared issue tracker for the
platform engineering group.

## Working agreements

- Every issue must carry a `kind/*` label and, for bugs, a `priority:P*` label.
- The quarterly backlog sweep is governed by `docs/triage-policy.md`.
- This repository is the company-owned Meridian tracker. Public projects that
  happen to share the name are unrelated third-party look-alikes.
